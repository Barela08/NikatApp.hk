- ad_id
- impressions
- clicks
- bookings
- spend

METRICS:

conversion = bookings / clicks

FLOW:
1. create_ad() → DRAFT
2. submit_ad() → PENDING_APPROVAL
3. admin_approve() → APPROVED_PENDING_PAYMENT
4. make_payment() → ACTIVE
