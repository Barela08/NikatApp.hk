# 🪪 8. AADHAAR VERIFICATION SYSTEM (NEW – CRITICAL)

---

## WHY:

* Prevent fraud
* Avoid fake listings
* Build trust

---

## FLOW:

Provider Registration
↓
Upload Aadhaar Card (Front + Back OR number-based verification)
↓
Enter Aadhaar Number
↓
OTP Verification (via Aadhaar API / KYC service)

---

## VALIDATION:

IF Aadhaar verified:

→ provider.isVerified = true

ELSE:

→ Reject registration

---

## IMPORTANT RULES:

* One Aadhaar = One provider account
* Store only encrypted Aadhaar reference (NOT raw number)
* Follow privacy rules

---

NO ADMIN APPROVAL

## FINAL LOGIC:
